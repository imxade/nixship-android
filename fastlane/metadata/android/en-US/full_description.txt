Nix Ship turns an ARM64 Android device into a self-contained application host and management client.

The APK includes a checksum-pinned Nix runtime and a CI-built Nix Ship control plane. It starts the server in an Android foreground service, keeps state in app-private storage, and opens the local dashboard in a hardened WebView. No separately hosted Nix Ship backend is required.

Create the owner account, sign in, change the password, deploy trusted flake repositories, access applications over the LAN, and optionally expose an application through a temporary Cloudflare Quick Tunnel.

Nix Ship is intended for private sideloading. Android force-stop, OEM battery controls, device resource limits, and incompatible workload binaries remain device constraints.
